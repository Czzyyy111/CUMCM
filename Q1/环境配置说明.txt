问题一 Python 运行环境
======================

Python 版本：3.11.7
虚拟环境目录：Q1\.venv
依赖清单：Q1\requirements.txt
MILP 建模接口：PuLP
MILP 求解器：开源 HiGHS（不需要商业许可证）

首次配置命令（在 SolutionC 工作区执行）：

    python -m venv Q1\.venv
    Q1\.venv\Scripts\python.exe -m pip install -r Q1\requirements.txt

运行问题一：

    Q1\.venv\Scripts\python.exe Q1\Q1_MILP.py

输入文件位置：

    C题\附件1.xlsx
    C题\附件2.xlsx
    C题\附件3\result1_1.xlsx
    C题\附件3\result1_2.xlsx

输出目录：

    Q1\outputs
    Q1\figures
    Q1\logs

说明：脚本不会修改原始附件和模板，而是复制模板后写入结果。
