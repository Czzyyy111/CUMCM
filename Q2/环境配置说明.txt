问题二 Python 运行环境
======================

建议 Python 版本：3.11
虚拟环境目录：Q2\.venv
依赖清单：Q2\requirements.txt
随机规划建模接口：PuLP
MILP/LP 求解器：开源 HiGHS（无需商业许可证）
绘图后端：Python matplotlib

首次配置命令（在 SolutionC 工作区执行）：

    python -m venv Q2\.venv
    Q2\.venv\Scripts\python.exe -m pip install -r Q2\requirements.txt

正式运行问题二：

    Q2\.venv\Scripts\python.exe Q2\Q2_Stochastic_CVaR.py

仅进行小规模流程检查：

    Q2\.venv\Scripts\python.exe Q2\Q2_Stochastic_CVaR.py --quick

只运行模型、不重绘图片：

    Q2\.venv\Scripts\python.exe Q2\Q2_Stochastic_CVaR.py --skip-figures

只重绘 Nature 风格图片：

    Q2\.venv\Scripts\python.exe Q2\Q2_nature_figures.py

输入文件位置：

    C题\附件1.xlsx
    C题\附件2.xlsx
    C题\附件3\result2.xlsx

主要输出：

    Q2\outputs\result2.xlsx
    Q2\outputs\问题二_随机规划_CVaR分析结果.xlsx
    （若同名工作簿已存在，则自动写为“问题二_随机规划_CVaR分析结果_更新版.xlsx”等新文件）
    Q2\source_data\*.csv
    Q2\figures_nature\*.png / *.svg / *.pdf / *.tiff
    其中图5为“风险权重—训练集期望利润/下尾CVaR90/加权目标值”对比图
    图6为“200条LHS训练情景—40条优化代表情景”的四因素扰动路线图
    Q2\logs\问题二_诊断日志.txt
    Q2\logs\运行摘要.json

说明：

1. 脚本不会修改原始附件或模板，只复制模板并写入 Q2\outputs。
2. 默认正式规模为 200 条 LHS 训练情景、2000 条验证情景和 5000 条测试情景。
3. --quick 输出只用于检查代码流程，日志中会明确标记，不应直接作为论文结果。
4. 正式流程先生成 200 条 LHS 训练路径，再按综合压力等频分层压缩为 40 条加权代表路径求解；五个风险权重分别求解完整随机 MILP，不固定其他权重的作物支持集。若达到时间上限，应结合输出的 MIP 间隙和方案差异诊断解释结果。
