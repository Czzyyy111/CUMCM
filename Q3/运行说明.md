# 问题三运行说明

## 方法

问题三复用问题二的随机 MILP、农业硬约束、训练—验证—测试隔离与 90% 下尾 CVaR，只将独立随机场景升级为“气候—农资通胀—市场景气—作物组行情”的分层公共因子 Copula 场景。

## 安装与运行

```powershell
cd Q3
python -m pip install -r requirements.txt
python Q3_Hierarchical_Factor_CVaR.py --quick
python Q3_Hierarchical_Factor_CVaR.py --time-limit 60
```

快速模式只检查完整流程，不应用于论文。正式运行先对各个 CVaR 风险权重求解完整 MILP，再冻结问题二与问题三方案完成相关强度敏感性评价，并冻结最终问题三方案完成公共因子消融。耗时主要来自五个风险权重候选的 MILP 时间上限。

若主模型已成功运行、只需重新绘图：

```powershell
python Q3_nature_figures.py
```

## 主要输出

- `outputs/result3.xlsx`：最终逐地块种植方案；
- `outputs/问题三_分层公共因子_CVaR分析结果.xlsx`：完整结果与诊断；
- `figures_nature/`：SVG、PDF、PNG、TIFF 论文图；
- `source_data/`：绘图和复核用 CSV；
- `logs/`：求解器与有效性检查；
- `参数基准与显示含义.md`：论文参数解释材料。
