# 2024 年高教社杯全国大学生数学建模竞赛 C 题解答

本仓库用于整理 2024 年高教社杯全国大学生数学建模竞赛 C 题的题目附件、建模分析、Python 实验代码、求解结果与论文写作材料。

当前已完成问题一：在 2024—2030 年规划期内，针对“超产部分滞销浪费”和“超产部分按正常价格的 50% 销售”两种情形，建立确定性多期混合整数线性规划模型，并输出逐地块、逐年份、逐季次的种植方案。

## 问题一方法

问题一采用确定性多期混合整数线性规划（MILP）。模型以地块—年份—季次—作物种植面积为核心决策变量，同时考虑：

- 各类土地的适种规则与面积平衡；
- 水浇地单季水稻或两季蔬菜的互斥选择；
- 连续重茬限制；
- 滚动三年豆类轮作；
- 最小种植面积与作物分散度；
- 预期销售量上限及超产部分的分段销售收入。

模型通过 PuLP 构建，并调用 HiGHS 求解器计算两种销售情形。

## 环境配置与运行

建议使用 Python 3.11。在仓库根目录执行：

```powershell
cd Q1
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python Q1_MILP.py
python Q1_nature_figures.py
```

程序读取 `C题/` 中的原始附件，结果写入 `Q1/outputs/`、`Q1/logs/` 和 `Q1/figures_nature/`。完整依赖版本及环境说明见 `Q1/requirements.txt` 和 `Q1/环境配置说明.txt`。

## 主要结果

在当前确定性参数和管理约束下：

- 超产部分滞销浪费情形的七年累计利润为 4066.72 万元；
- 超产部分按正常价格的 50% 销售情形的七年累计利润为 6175.26 万元；
- 后一情形的累计利润提高 51.85%。

其中，滞销浪费情形是在 240 s 时间上限内得到的整数可行方案，最终相对间隙约为 1.482%；半价销售情形在 1% 容差内完成求解，最终相对间隙约为 0.564%。具体种植安排及诊断结果以 `Q1/outputs/` 和 `Q1/logs/` 中的文件为准。

本仓库内容用于数学建模学习、复现和交流。模型中的最小种植面积、最大分布地块数等参数，是对题目定性管理要求的工程化量化；若用于实际农业规划，还需结合当地市场、成本、气候和经营条件重新校准。
