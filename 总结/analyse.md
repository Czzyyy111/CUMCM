# 2024 年高教社杯数学建模竞赛 C 题分析

## 一、题目总体认识

本题研究华北山区某乡村在有限耕地资源、作物适种条件、轮作要求和市场约束下的 2024—2030 年农作物种植策略。

题目的核心是：在土地、季节、适种条件和轮作要求形成的硬约束下，逐步把确定性收益最大化扩展为不确定环境下的风险决策，再扩展到变量相关、作物相互影响的系统决策。

三问并不是彼此割裂的问题，而是同一决策框架的逐层升级：

1. 问题一：确定条件下的利润最大化；
2. 问题二：参数存在不确定性时的收益—风险权衡；
3. 问题三：进一步考虑参数相关性以及作物替代、互补关系。

因此，后续建模宜采用统一的“地块—作物—年份—季次”决策框架，在各问中依次升级收益函数、不确定性描述和作物交互机制。

## 二、问题一：确定条件下的多期种植优化

| 分析维度 | 内容 |
|---|---|
| 问题分类 | **确定性、多阶段、带轮作约束的最优决策问题**。更具体地说，可归入混合整数线性规划（MILP）或带分段收益的线性规划问题。 |
| 核心决策 | 决定 2024—2030 年中，每个地块、每个季次、每种作物分别种植多少亩；还需要决定某种作物是否在某地块种植，以表达最小种植面积和种植分散度。 |
| 优化目标 | 最大化七年总利润，即销售收入减去种植成本。题目给出的两种滞销处理方式对应两套不同的收益函数。 |
| 情形（1）的收益逻辑 | 作物产量超过预期销售量后，超出部分收入为零。因此，有效销量为总产量和预期销售量的较小值。继续增种一种已经达到销售上限的作物，只会增加成本。 |
| 情形（2）的收益逻辑 | 超产部分仍能以原销售价格的 50% 出售。收益函数具有两个斜率：预期销售量以内按正常价格，超过后按半价。这是典型的**分段线性收益**。 |
| 主要约束 | ① 各地块每季面积守恒；② 作物与地块类型相容；③ 水浇地在“单季水稻”和“两季蔬菜”之间选择；④ 普通大棚第一季种蔬菜、第二季种食用菌；⑤ 智慧大棚两季均种蔬菜；⑥ 同一作物不得在同一地块连续重茬；⑦ 任意连续三年内，每个地块至少安排一次豆类；⑧ 考虑最小种植面积和作物种植地块数量。 |
| 推荐主模型 | 以种植面积为连续变量，以“是否种植”为 0-1 变量，建立多期 MILP。销售量以内与超出部分可分别设置辅助变量，使两个情形都保持线性。 |
| 可参考算法 | Gurobi、CPLEX、SCIP、CBC 等整数规划求解器；也可使用遗传算法、模拟退火作为备选。但本题约束明确，MILP 的可解释性、可行性保证和论文表达通常更好。 |
| 题目逻辑与模型的必然联系 | 题目不仅问“哪种作物利润高”，还要求决定“在哪块地、哪一年、哪个季节种多少”。轮作约束使某一年的决策影响以后年份，因此不能逐年独立贪心，必须把 2024—2030 年联合优化。 |
| 最值得注意的数据口径 | 附件没有单列“预期销售量”，通常需要用 2023 年各种作物的实际种植面积乘对应亩产量，汇总得到基准销售量；销售价格以区间给出，常见做法是采用区间均值。正式求解前需要明确并记录这两个口径。 |
| 可能的陷阱 | 只比较亩均利润；忽略 2023 年种植对 2024 年重茬的影响；将豆类约束误写成七年只种一次；只限制总面积却不限制地块适种性；先算产量再强行截断收入，导致模型无法保持线性；完全不处理“小面积、过度分散”等管理要求。 |

### 问题一的思考重点

问题一表面上是利润最大化，实质上是一个跨年度的资源配置问题。高利润作物并不必然应该大量种植，因为销售上限、重茬禁令和三年豆类轮作会共同限制其种植规模。合理方案应在短期利润和未来年份的可行性之间作出平衡。

## 三、问题二：参数不确定条件下的风险优化

| 分析维度 | 内容 |
|---|---|
| 问题分类 | **共享事前决策的情景随机混合整数规划 + CVaR 下行风险控制**。种植面积在所有情景中相同，情景只改变销量、亩产、成本、价格和可实现利润。 |
| 相对问题一的变化 | 地块面积、适种性、重茬、豆类轮作、最小面积和分散度仍是确定性硬约束；随机性进入产量上限、销量上限、成本系数、价格系数与利润函数，而不是把全部农业约束概率化。 |
| 基准口径 | 2023 年各作物实际种植面积乘对应亩产量后按作物汇总，作为销量基准；附件价格区间仍取中点，未来趋势通过情景乘数表达。主模型采用“超产部分滞销、收入为 0”，半价销售只作为扩展敏感性情形。 |
| 销量分布 | 小麦、玉米年增长率服从 (U(5\%,10\%))，沿情景路径逐年复合；其他作物各年销量相对 2023 年基准服从 (U(-5\%,5\%))，不进行无依据的复合漂移。 |
| 亩产分布 | 各作物各年亩产乘数服从 (U(0.90,1.10))。亩产是连续变量，因此不使用二项分布；二项或伯努利灾害冲击只适合另行开展极端天气敏感性分析。 |
| 成本与价格分布 | 成本年增长率取三角分布 (Tri(3\%,5\%,7\%))；粮食价格稳定；蔬菜价格年增长率取 (Tri(3\%,5\%,7\%))；食用菌年降幅取 (U(1\%,5\%))，羊肚菌固定下降 5%。三角分布边界属于工程假设，应在论文中说明并进行敏感性分析。 |
| 情景独立性 | 问题二暂令跨作物、跨参数的随机扰动相互独立，保留题目给出的单变量趋势；销量—价格—成本相关性及作物替代、互补关系留到问题三处理，以保持三问递进。 |
| 训练情景 | 使用拉丁超立方抽样生成 200 条完整的 2024—2030 年路径作为训练池；再按需求、产量、价格与成本构成的综合压力指标划分 40 个等频层，每层选取最接近多维中心的真实路径作为优化训练情景，代表概率均为 0.025。论文中的训练目标函数按这 40 条代表路径计算，完整 200 条训练池另作内部重评价。 |
| 验证与测试 | 使用随机种子相互独立的 2000 条蒙特卡洛情景选择风险权重，再使用 5000 条全新情景进行最终样本外评价。测试时冻结种植方案，不允许针对每条测试情景重新优化，避免完美信息与样本内乐观偏差。 |
| 随机销售约束 | 情景 (s) 中正常销量 (q_{ct}^{(s)}\) 同时满足 (q_{ct}^{(s)}\le D_{ct}^{(s)}\) 与 (q_{ct}^{(s)}\le\sum_{i,k}Y_{ickt}^{(s)}x_{ickt}\)。种植变量 (x\) 对所有情景共享，销售变量 (q\) 随情景变化。 |
| 情景利润 | 年度利润为随机正常销售收入减随机种植成本，七年利润为各年名义利润之和。超出随机需求的产量不形成收入，但成本已经发生，因此滞销风险会直接传递到利润分布。 |
| CVaR 目标 | 取置信水平 90%，最大化 ((1-\lambda)E[\Pi]+\lambda CVaR_{0.90}^{-}(\Pi)\)。其中下尾 CVaR 是利润最低 10% 情景的平均值；计算 (\lambda=0,0.2,0.4,0.6,0.8\) 的候选方案。 |
| 风险权重选择 | 在独立验证集中，先保留期望利润不低于最高值 97% 的方案，再选择下尾 CVaR 最高者；若 CVaR 在 0.01% 数值容差内并列，则采用预先设定的中等风险权重 (\lambda=0.4\) 作为解释性平局规则。5000 条测试情景不得再次参与风险权重选择。 |
| 大规模求解策略 | 对每个风险权重分别构建完整随机 MILP，作物启用变量与种植面积均重新优化，不跨权重固定整数支持集。每个候选均记录求解时间、MIP 相对间隙，并自动比较其与风险中性方案的面积及作物支持集差异；达到时限的整数可行解不宣称为全局最优。 |
| 最终输出 | `result2.xlsx` 填写一套确定的七年种植面积；概率结果作为方案评价，报告期望利润、标准差、P10/P50/P90、下尾 CVaR、累计及年度亏损概率、滞销率和典型情景年度利润路径。 |
| 可能的陷阱 | 给每个情景一套不同种植面积；使用优化情景自我评价；用 5000 条测试情景反复选择参数；把 CVaR 误写成亏损概率；只展示均值而不展示尾部；把一个风险权重的整数支持集固定后冒充其他权重的独立优化结果。 |

### 问题二的思考重点

问题二的关键不是简单地把问题一中的参数替换成随机数，而是保证随机性通过情景产量、销量上限和利润函数真实影响同一套可执行种植方案。优化、风险权重选择和最终评价必须使用相互隔离的情景集。论文中应重点解释：为了改善最差 10% 情景的平均利润，方案牺牲了多少期望利润；若各风险权重在完全独立求解后仍于数值容差内得到同一方案，应将其解释为当前情景假设与约束下的风险前沿退化，中等风险权重只作为预先声明的平局规则，不能声称存在并未观察到的风险改善。

### 问题二的最终实验流程

1. 读取附件 1、附件 2，复用问题一的地块—作物—年份—季次变量和硬约束；
2. 根据题目区间构造销量、亩产、成本和价格的边际分布；
3. 生成 200 条 LHS 训练路径，并建立共享种植决策的样本平均近似模型；
4. 分别构建并求解五个 CVaR 权重对应的完整随机 MILP，所有权重均重新优化作物选择与种植面积；
5. 在 2000 条独立验证情景中按“至少保留 97% 最高期望利润，再最大化下尾 CVaR”选择方案；
6. 冻结最终方案，在 5000 条全新蒙特卡洛情景中计算利润分布与风险指标；
7. 从测试利润中选取最差、P10、P50、P90 和最佳典型情景，绘制年度利润路径；
8. 将确定性种植面积写入 `result2.xlsx`，同时导出分析工作簿、源数据、诊断日志和论文级中文图形。

## 四、问题三：相关性与作物相互作用下的系统优化

| 分析维度 | 内容 |
|---|---|
| 问题分类 | **具有相关随机变量和作物交互关系的随机优化问题**。根据交互关系的表达方式，可形成随机 MILP、混合整数二次规划（MIQP）或非线性规划。 |
| 相对问题二的本质升级 | 问题二主要研究各参数各自波动；问题三进一步研究这些变量是否“一起变化”，以及一种作物的种植、价格或销售是否影响其他作物。核心从边际分布升级为**联合分布与交互机制**。 |
| 可替代性 | 两种用途或消费场景相近的作物之间可能相互竞争。例如一种作物涨价后，其需求可能转移到替代作物。数学上可用负的交叉关系或交叉价格弹性表示。 |
| 互补性 | 一种作物销量增加可能带动另一种作物销量，或合理组合种植能够降低管理风险、改善轮作。数学上可通过正的交互系数、组合收益或联合需求表达。 |
| 参数相关性 | 销量、价格、成本可能受共同的市场、气候或通胀因素驱动。例如成本普遍上升，或减产伴随价格上涨。这意味着不能再分别独立抽取随机数。 |
| 推荐建模结构 | 第一层建立作物替代—互补关系矩阵；第二层建立销售量、价格、成本和亩产量的相关结构；第三层生成相关情景；第四层在这些情景下进行风险优化。 |
| 相关情景生成 | 可使用相关系数矩阵配合 Cholesky 分解、Gaussian Copula、秩相关的 Iman–Conover 方法，或设置“气候因子、市场因子、成本因子”等潜在公共因子。 |
| 替代—互补关系表达 | 简洁方案是构造作物关系矩阵：替代关系取负值、互补关系取正值；更经济学化的方案是建立价格—需求弹性模型；若存在种植组合效应，可加入两种作物同时种植的交互收益项。 |
| 模拟数据原则 | 由于附件只有一个基准年份，难以从数据直接可靠估计大量相关系数。因此应进行有依据的假设、分组设定系数，并开展敏感性分析，不能声称这些关系是从单年数据中统计识别出来的。 |
| 可参考算法 | Copula 或 Cholesky 相关模拟、蒙特卡洛或拉丁超立方抽样、情景聚类与削减、随机 MILP、MIQP、交互项线性化、CVaR 优化。若模型规模过大，可用遗传算法或粒子群算法辅助搜索。 |
| 与问题二的比较方式 | 不只比较总利润，还应比较期望利润、最差情景利润、CVaR、种植结构多样性、地块调整幅度、滞销比例和方案跨情景稳定性。 |
| 题目逻辑与模型的必然联系 | 如果作物存在替代性，集中种植若干相似作物并不能真正分散市场风险；如果价格与产量负相关，则“低产”未必等比例导致低收入。因此，忽略相关性会错误估计组合风险，问题三必须改变情景的联合生成方式，甚至改变收益函数。 |
| 可能的陷阱 | 随意给出一张相关矩阵却不解释依据；把相关性等同于因果关系；只生成相关数据但仍使用问题二原模型；比较时使用不同随机样本，导致差异来自抽样而非模型；交互系数过强，产生不合理的负需求或极端价格。 |

### 问题三的思考重点

问题三真正考查的是“组合效应”。若两类作物高度替代，则同时大量种植并不能有效分散市场风险；若产量下降通常伴随价格上升，则独立模拟产量和价格会夸大或低估真实风险。模型必须通过联合情景或交互函数把这种关系传递到最终种植方案中。

## 五、三问的递进关系

| 层次 | 问题解决的核心 | 模型升级方向 |
|---|---|---|
| 问题一 | 在确定的市场和生产条件下，找到满足农业规则的利润最大方案。 | 建立基本的多期混合整数规划模型。 |
| 问题二 | 当未来参数会波动时，在收益和风险之间进行权衡。 | 引入随机情景、鲁棒性或 CVaR 风险度量。 |
| 问题三 | 当这些波动彼此相关、作物之间又会相互影响时，重新评价真正的组合风险与种植结构。 | 引入联合分布、相关情景以及替代—互补关系。 |

## 六、后续建模时应优先明确的问题

1. 如何由 2023 年数据确定各作物的预期销售量基准；
2. 销售价格区间采用均值、抽样值还是其他代表值；
3. “不能连续重茬”是否同时约束跨年相邻季次；
4. “三年内至少种植一次豆类”应采用怎样的滚动时间窗口；
5. 单个地块的最小种植面积和单种作物允许分布的最大地块数量如何量化；
6. 问题二采用随机规划还是鲁棒优化，以及风险厌恶程度如何设定；
7. 问题三中作物替代、互补和参数相关关系的假设依据及敏感性验证方式。

以上内容仅为题型识别和建模方向分析，尚未进行数据计算、参数拟合或方案求解。
