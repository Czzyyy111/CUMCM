# 问题三：相关性与作物交互作用下的种植策略——建模复用指南

> 适用场景：只有一个基准年份或缺少完整历史序列，但题目要求考虑销量、亩产量、成本、价格之间的相关性，以及作物替代性、互补性，并在既有种植优化模型上给出未来多年方案。

## 问题类型

**具有相关随机变量、作物交互关系和跨期农业约束的多阶段随机混合整数规划问题。**

问题可分为四层：

1. **农业约束层**：土地容量、地块—作物适配、季次、水浇地模式、大棚模式、禁止重茬、滚动三年豆类轮作、最小面积和分散度约束；
2. **不确定性层**：未来销量、亩产量、种植成本和销售价格保持题目给出的边际波动范围；
3. **相关与交互层**：公共气候、农资通胀和市场景气因子产生联合波动，作物组因子产生组内联动，价格弹性及前茬效应表达替代性与互补性；
4. **风险决策层**：在全部情景中共享同一套种植决策，以期望利润和下尾 CVaR 共同评价方案。

单年基准数据不能支持高维相关系数的统计估计，因此相关结构应表述为**经济机理约束下的情景假设**，而不是“从 2023 年样本识别出的真实相关关系”。

## 候选模型

| 编号 | 候选模型 | 作用 | 是否推荐为主模型 |
|---|---|---|---|
| M0 | 独立情景随机 MILP + CVaR | 复现上一问，作为基准 | 否，仅作基线 |
| M1 | 人工相关矩阵 + Cholesky/Gaussian Copula + MILP | 实现简单，但高维矩阵难解释、易非正定 | 否 |
| M2 | 三公共因子 Gaussian Copula + 随机 MILP + CVaR | 能表达气候、成本和市场的共同冲击 | 可作简化主模型 |
| M3 | **三公共因子 + 作物组因子 + 替代弹性 + 豆类前茬增益 + 随机 MILP + CVaR** | 同时覆盖变量相关性、作物替代性和农业互补性 | **推荐** |
| M4 | M3 + t-Copula 或联合不利冲击 | 检验联合尾部风险 | 压力测试模型 |

### 推荐模型的公共因子

1. 气候生产因子 $F_t^W$：正值表示气候有利；
2. 农资通胀因子 $F_t^C$：正值表示种子、化肥、人工、能源和运输成本上涨较快；
3. 市场景气因子 $F_t^M$：正值表示消费需求和流通环境较好；
4. 作物组市场因子 $G_{g,t}$：表示豆类、主粮、杂粮薯类、豆荚类蔬菜、茄果瓜类、叶菜甘蓝类、根茎类、食用菌等组内行情。

建议的基准传导结构如下。表中数值为**潜变量载荷**，不是直接乘到原始参数上的百分比。

| 随机变量 | 气候 $F^W$ | 通胀 $F^C$ | 市场 $F^M$ | 作物组 $G_g$ | 说明 |
|---|---:|---:|---:|---:|---|
| 露地亩产量 | +0.65 | 0 | 0 | 0 | 气候有利时共同增产 |
| 水浇地亩产量 | +0.45 | 0 | 0 | 0 | 灌溉削弱气候暴露 |
| 普通大棚亩产量 | +0.25 | 0 | 0 | 0 | 设施进一步削弱气候暴露 |
| 智慧大棚亩产量 | +0.15 | 0 | 0 | 0 | 环境控制能力最强 |
| 种植成本增长率 | 0 | +0.70 | 0 | 0 | 不同作物成本共同上涨 |
| 预期销量 | 0 | 0 | +0.35 | +0.45 | 整体市场与类别市场共同作用 |
| 蔬菜价格增长率 | -0.20 | +0.30 | +0.20 | +0.30 | 丰产压价、成本传导、需求拉动 |
| 普通食用菌价格变化 | 0 | +0.20 | +0.20 | +0.35 | 保留题目给定的下降边际分布 |
| 粮食价格 | 0 | 0 | 0 | 0 | 按题意保持基本稳定 |
| 羊肚菌价格 | 0 | 0 | 0 | 0 | 按题意固定年降 5% |

标准化潜变量的一般形式为

$$
Z_{cvt}=\sum_k a_{cvk}F_{k,t}
+\sqrt{1-\sum_k a_{cvk}^{2}}\,\varepsilon_{cvt},
$$

再令

$$
U_{cvt}=\Phi(Z_{cvt}),
$$

并将 $U_{cvt}$ 输入上一问的逆分布函数。这样只改变变量的联合变化方式，不改变亩产量 ±10%、成本三角分布、销量 ±5% 等题面边际范围。

公共因子可设置年度持续性：

$$
F_{k,t}=\phi_kF_{k,t-1}+\sqrt{1-\phi_k^2}\eta_{k,t}.
$$

推荐基准值为

$$
\phi_W=0.20,\qquad
\phi_C=0.60,\qquad
\phi_M=0.40,\qquad
\phi_G=0.30.
$$

### 作物替代与互补

替代性通过稀疏的组内交叉价格弹性表达：

$$
\ln D_{ct}^{(s)}=
\ln \widetilde D_{ct}^{(s)}
-\eta_c\ln\frac{P_{ct}^{(s)}}{\bar P_{ct}}
+\sum_{j\in S(c)}e_{cj}\ln\frac{P_{jt}^{(s)}}{\bar P_{jt}}.
$$

- 自价格弹性 $\eta_c>0$：自身价格上涨时自身需求下降；
- 替代品交叉弹性 $e_{cj}>0$：替代品涨价时本作物需求增加；
- 若无明确消费证据，不应随意设置大量互补品对；
- 推荐自价格弹性：粮食 0.10～0.20、蔬菜 0.25～0.45、食用菌 0.30～0.50；
- 推荐组内交叉弹性：0.05～0.15，并限制每种作物的交叉弹性总和。

农业互补性优先使用题面已有依据：豆类前茬对后续非豆类作物产生 0%～5% 的亩产增益，基准取 3%。使用辅助变量线性化后仍可保持 MILP 结构。

## 模型选择依据

选择 M3 作为主模型，依据如下：

1. **与数据量匹配**：只有单年汇总基准，无法可靠估计完整相关矩阵，低维公共因子比高维协方差矩阵更稳妥；
2. **保持题目口径**：Copula 只改变各随机变量分位数的联合排序，能够保留上一问的边际分布和趋势；
3. **相关结构天然可行**：因子模型构造的相关矩阵天然半正定，避免手工矩阵无法 Cholesky 分解；
4. **经济解释清晰**：成本—价格正相关、产量—价格负相关和需求—价格正相关分别来自不同公共冲击；
5. **避免维度失控**：只需设定少量载荷、持续系数和弹性区间，而不是估计所有作物两两关系；
6. **兼容既有模型**：土地、轮作、销量截断、情景利润和 CVaR 结构均可从上一问复用；
7. **便于逐层验证**：M0—M4 构成自然消融链条，可解释每项机制对风险和决策的贡献；
8. **保持可求解性**：公共因子只改变情景系数，交叉需求在情景生成阶段计算，豆类前茬增益可线性化，主体仍为随机 MILP。

风险目标保持为

$$
\max\quad
(1-\lambda)E[\Pi]
+\lambda\mathrm{CVaR}_{0.90}^{-}(\Pi),
$$

但应在相关场景下重新考察

$$
\lambda\in\{0,0.2,0.4,0.6,0.8\},
$$

不能直接沿用上一问选出的风险权重。

## 数据要求

### 必需数据

| 数据 | 最低字段 | 用途 |
|---|---|---|
| 地块基础数据 | 地块编号、地块类型、面积 | 土地容量与适种约束 |
| 作物基础数据 | 作物编号、名称、类别、允许地块和季次 | 作物分组及适配约束 |
| 基准经营数据 | 亩产量、亩成本、价格区间 | 构造基准收入成本 |
| 基准种植记录 | 地块、作物、面积、季次 | 推导基准销量并衔接重茬约束 |
| 上一问模型及结果 | 随机分布、种植方案、CVaR设置、输出指标 | 建立 M0 基线并复用硬约束 |
| 专家先验表 | 公共因子载荷、持续系数、弹性区间、互补增益 | 构造相关情景和交互机制 |

### 可选增强数据

- 多年逐作物销量、亩产量、成本和价格序列；
- 月度或年度农资价格指数；
- 当地温度、降水、极端天气记录；
- 批发市场价格和成交量；
- 作物价格弹性或替代关系的文献区间。

若获得多年数据，可用收缩协方差、贝叶斯更新或因子载荷回归修正先验；若没有，则必须把参数称为“情景假设”，并通过敏感性分析给出结论边界。

### 情景数据划分

- 训练池：生成相关的完整多年路径，用于候选方案优化；
- 代表情景：从训练池中进行保均值、保相关、保尾部的情景削减；
- 验证集：只用于重新选择风险权重和模型参数；
- 测试集：只用于冻结方案后的最终样本外评价；
- 各集合使用不同随机种子，测试集不得反复参与调参。

若代表情景只有 40 条，则 90% 下尾 CVaR 主要由 4 条路径决定。计算资源允许时，推荐增加至 60～80 条代表路径，或使用显式保尾部的加权情景削减。

## 验证指标

### 场景生成有效性

| 检查项 | 推荐指标或阈值 | 原因 |
|---|---|---|
| 相关矩阵可行性 | 最小特征值不小于 -$10^{-8}$ | 防止数值非正定 |
| 目标相关实现程度 | Spearman 相关平均绝对偏差不超过 0.05；符号正确率 100% | 验证模拟实现设定关系 |
| 边际分布保持 | 均值、标准差、P10/P50/P90与理论值或独立版本接近；范围满足题面 | 防止公共因子改变波动口径 |
| 非法值 | 负销量、负价格、负成本数量为 0 | 保证经济意义 |
| 截断比例 | 原则上为 0；若设置需求保护区间，应单独报告 | 防止大量截断扭曲相关性 |
| 情景削减误差 | 全训练池与代表情景的均值、标准差、相关系数、基准方案CVaR差异尽量不超过 2% | 防止削减丢失尾部结构 |

KS 检验可作为边际分布的辅助诊断，但由于样本由人为分层和 Copula 生成，不应仅凭 $p$ 值宣称分布正确。

### 优化与风险指标

- 七年期望利润、利润标准差；
- P10、P50、P90；
- 下尾 $\mathrm{CVaR}_{0.90}^{-}$；
- 累计亏损概率和年度亏损概率；
- 平均滞销率与分作物滞销率；
- 最差情景利润；
- MIP 求解状态、best bound、相对间隙和耗时；
- 面积平衡、最小面积、分散度、重茬和豆类轮作违规数，均应为 0。

### 问题二与问题三的公平比较

必须将问题二方案和问题三方案冻结后，放入**同一批相关测试场景**评价。不能直接比较问题二在独立情景下的旧指标与问题三在相关情景下的新指标。

对每条测试路径计算

$$
\Delta\Pi_s=\Pi_s^{Q3}-\Pi_s^{Q2},
$$

并使用配对 Bootstrap 给出平均利润差、P10 差和 CVaR 差的 95% 区间。同时比较：

- 种植面积的 $L_1$ 距离；
- 作物支持集 Jaccard 相似度；
- 作物类别集中度或多样性指数；
- 年度调整幅度；
- 相关场景下风险恶化是否被新方案缓解。

## 敏感性 / 稳定性分析

### 1. 相关强度敏感性

设置

$$
\kappa\in\{0,0.5,1.0,1.5\},
$$

其中 $\kappa=0$ 对应独立场景。公共载荷乘以 $\sqrt{\kappa}$，再重新计算个体噪声系数；不能直接放大相关矩阵而忽略正定性。

### 2. 消融实验

| 实验 | 公共相关 | 作物组相关 | 替代弹性 | 豆类互补 | 目的 |
|---|---:|---:|---:|---:|---|
| A0 | 否 | 否 | 否 | 否 | 复现问题二基线 |
| A1 | 是 | 否 | 否 | 否 | 识别全局共同冲击影响 |
| A2 | 是 | 是 | 否 | 否 | 识别类别内部联动影响 |
| A3 | 是 | 是 | 是 | 否 | 识别市场替代效应 |
| A4 | 是 | 是 | 是 | 是 | 完整问题三模型 |

每个实验同时执行两种评价：

1. 固定问题二方案，只改变情景生成方式，测量风险被重新估计的幅度；
2. 在相应模型下重新优化，测量种植决策主动调整带来的收益。

### 3. 关键参数敏感性

- 因子年度持续系数 $\phi_W,\phi_C,\phi_M,\phi_G$；
- 自价格弹性和交叉价格弹性；
- 豆类前茬增益 $\delta\in\{0,0.02,0.03,0.05\}$；
- Gaussian Copula 与自由度 ν=5 的 t-Copula；
- CVaR 置信水平 $\alpha\in\{0.85,0.90,0.95\}$；
- 风险权重 $\lambda$；
- 训练池规模、代表情景数和削减方法。

### 4. 随机与计算稳定性

- 至少使用 5～10 组随机种子重复生成训练、验证和测试情景；
- 报告利润、CVaR、滞销率的跨种子均值和标准差；
- 统计核心作物面积的变异系数和支持集入选频率；
- 对主要模型使用相近的求解时限与 MIP gap；
- 若相对间隙仍较大，只能称为“当前计算预算下的整数可行方案”，不能称为全局最优。

## 常见错误

1. 用不同作物在 2023 年的横截面价格、成本计算相关系数，并解释成未来年度共同波动；
2. 声称单年数据能够统计识别完整相关矩阵、价格弹性或跨年持续性；
3. 直接把公共因子按百分比加到原参数上，导致题面规定的边际分布和上下界被改变；
4. 手工填写巨大相关矩阵却不检查半正定性；
5. 把相关性写成因果关系，或用一个相关系数同时解释供给、需求和成本传导；
6. 已用交叉价格弹性表达替代关系，又给替代品需求施加强负相关，造成重复计算；
7. 作物分组过细、两两弹性过多，主观参数数量远大于数据支持能力；
8. 公共因子载荷平方和超过 1，造成个体噪声方差为负；
9. 价格弹性修正后出现负需求，或大量需求被强制截断；
10. 使用问题二的独立测试结果直接和问题三相关测试结果比较；
11. 问题二和问题三方案使用不同测试场景，差异来自抽样噪声；
12. 加入相关性后仍固定使用上一问的 $\lambda$，不重新验证风险偏好；
13. 用优化训练情景自我评价，或反复利用测试集选择参数；
14. 只做消融实验，不检查边际分布、实现相关性和情景削减误差；
15. 只报告期望利润，不报告标准差、尾部分位数、CVaR、滞销率和最差情景；
16. MIP 达到时限且间隙较大，却写成“求得全局最优解”；
17. 强行使用 MIQP、遗传算法或深度学习，而忽略本题可保持线性和可解释性的优势。
